# Web Serial 수동 회귀 테스트

이 문서는 `WebSerialTransport` 변경 후 실제 CWT-TH04S와 USB-RS485 어댑터에서 확인할 최소 절차다. 자동 테스트로 재현할 수 없는 브라우저 권한 창과 물리 장치 분리를 검증한다.

## 사전 조건

- 데스크톱 Chrome 또는 Edge로 운영자가 설정한 HTTPS 주소(예: `https://app.example.com`)에 접속한다.
- CWT-TH04S는 9600 baud, 8N1, Slave ID 100으로 설정되어 있다.
- RS485 A/B와 전원 배선을 확인한다.

## 1. 정상 연결과 측정

- [ ] `Serial Port 연결`을 누르고 USB-RS485 port를 선택한다.
- [ ] 상태가 `연결됨`으로 변경된다.
- [ ] TX가 `64 03 00 00 00 02 CD FE`로 표시된다.
- [ ] 온도와 습도가 3초마다 갱신된다.
- [ ] 브라우저 Console에 처리되지 않은 오류가 없다.

## 2. 사용자 연결 해제

- [ ] 측정 중 `연결 해제`를 누른다.
- [ ] 상태가 `연결 안 됨`으로 변경된다.
- [ ] 연결 해제 이후 추가 TX가 발생하지 않는다.
- [ ] 오류 안내가 남지 않는다.
- [ ] 다시 `Serial Port 연결`을 눌러 정상적으로 새 session을 시작할 수 있다.

## 3. 물리 USB 분리

- [ ] 측정 중 USB-RS485 어댑터를 PC에서 분리한다.
- [ ] timeout을 반복하지 않고 `장치 분리됨` 또는 `통신 오류` 상태로 전환된다.
- [ ] polling이 중지되고 추가 TX가 발생하지 않는다.
- [ ] 사용자에게 연결 종료 오류가 표시된다.
- [ ] 화면이나 브라우저가 멈추지 않는다.

## 4. 장치 재연결

- [ ] USB-RS485 어댑터를 다시 연결한다.
- [ ] 사용자 동작 전에는 자동으로 Write나 polling을 시작하지 않는다.
- [ ] `Serial Port 연결`을 누르고 port를 선택하면 다시 측정된다.
- [ ] 이전 session의 늦은 응답이 새 측정값이나 상태를 변경하지 않는다.

## 결과 기록

테스트 일시, 브라우저 버전, USB-RS485 모델과 실패 항목을 개발 계획서의 진행 결과에 기록한다.
